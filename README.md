# Advanced Student Performance Prediction

## Project Description

This project predicts student performance using different Machine Learning regression and classification algorithms.

It includes a simple **Tkinter GUI** where users can enter student details and predict marks and performance categories.

## Machine Learning Algorithms Used

1. Linear Regression
2. Multiple Linear Regression
3. Polynomial Regression
4. Binary Logistic Regression
5. Multinomial Logistic Regression
6. Ordinal Logistic Regression

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Statsmodels
- Tkinter

## Features

- Enter student name and academic details
- Predict marks using different regression algorithms
- Predict Pass or Fail
- Predict Low, Medium, or High performance
- Predict Poor, Average, Good, or Excellent performance
- Display graphs for model predictions
- Simple graphical user interface

## Input Features

The project uses the following student information:

- Study Hours
- Attendance Percentage
- Assignment Marks
